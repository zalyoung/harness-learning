# AGENTS.md

## Commit Message Convention

- Format: `submit Week{N} Chapter{NN} homework` (e.g., `submit Week1 Chapter01 homework`)
- Use English, lowercase, imperative mood

## Homework Format

- **Directory**: `Week{N}/Chapter{NN}/`
- **File**: `homework.md`
- **Title**: `# Harness Learning — Week {N} · Chapter {NN}`
- **Tasks**: Each task section uses `## 任务 {N}：{标题}`, containing:
  - `### 目标` — first copy the original task objective, then write the answer below
  - `### 验证结果` or `### 体会` or `### 关键代码片段` + `### 循环分析` — task deliverables (screenshots, code, analysis)
- **Language**: Chinese for homework content, English for commit messages
